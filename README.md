# PrismGallery

A privacy-first Android gallery with a calm, modern interface.

## First build
- Native Android app using Kotlin and Jetpack Compose
- Local photo library powered by Android MediaStore
- Photo grid and full-screen viewer foundation
- Albums, search, and settings planned as separate experiences
- Floating navigation pill with a solid frosted surface (not glass-like transparency)

## Design direction
PrismGallery takes organizational cues from Aves, local-first simplicity from Fossify Gallery, and familiar photo browsing patterns from Google Photos—without requiring a cloud account.

## Build
Open the project in Android Studio and let Gradle sync. The app targets modern Android versions while retaining compatibility with Android 8.0+.
